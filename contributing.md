# Contributing

### What belongs here

Data that is:
- Useful for research, teaching, or data visualization. Preferably applied micro-related, but doesn't always have to be
- Free. And preferably publicly available, but a free data use agreement is also fine

### Ways to contribute

You can suggest a new dataset or point out an error, broken link, etc. by:
- Opening an [issue](https://github.com/toddrjones/datasets/issues/new) with your suggestion
- Editing the list yourself with a propose changed
- Emailing me

I will review and decide if I want to include the change, but no guarantees.

### Sample entry

- [Dataset name](https://link-to-data) - One-line description of what it contains
  - Years: 1990-present; Access: Public
  - Unit of observation, geography, notable variables, quirks, how it links to other data, etc.
  - From [Paper that introduced the data](https://link-to-paper)

Note that only the first line is required
